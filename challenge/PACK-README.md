# Notes-to-proposal challenge

**Start with `BRIEF.md`.**

| File | What it is |
|------|-----------|
| `BRIEF.md` | The problem to solve. |
| `challenge-generator.html` | The proposal tool. Open it in a browser (offline, no login). |
| `proposal-schema.md` | A reference to the data the tool understands today. |
| `schema.json` | The same reference, machine-readable. |
| `sample-inputs/` | Example adviser notes and a voice-note transcript, each with an illustrative output. |

To get a feel for the tool, open it, press F12 for the console, and run
`window.challenge.example()`.

All data in this pack is fictional.
